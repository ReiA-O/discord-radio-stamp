# 後日追加する特典カード素材

このディレクトリは非公開releaseの内部素材です。`public/`や公開ストレージへ置かず、Discordの本人限定応答にだけPNGを添付します。今回の正式素材は未作成です。公開・配備・運用起動は別途承認を受けるまで行いません。

`active.json`は4096 byte以下のJSONオブジェクトです。現在の空オブジェクト `{}` と、指定のない日数は従来の仮カードを生成します。指定できるキーは `10`、`30`、`60`、`100`、`300`、`365` だけです。

正式素材を用意した後の対応表の例：

```json
{"10":"day-10-v1.png","30":"day-30-v2.png"}
```

ファイル名は対応する日数の `day-<日数>-v<正整数>.png` というbasenameだけを使います。例：`day-10-v1.png`。先頭ゼロの版番号、URL、絶対パス、サブディレクトリ、パスの移動、リンクは使えません。

素材は1200×800 pixelの完成PNGで、ファイル全体が1MiB（1,048,576 byte）以下である必要があります。署名・寸法・PNG decodeを検証し、読めた元のbytesをそのまま添付します。画像への名前・日数・文字の重ね描きはしません。必要な文字やデザインは完成画像に含めてください。

資格は毎回本人のJST参加履歴で確認してから素材を読み込みます。指定した素材の欠損・破損・過大サイズ、不正な対応表、ディレクトリやファイルのリンクは固定エラーになります。指定済みの正式素材が読めない場合に仮カードへ黙って置き換えることはしません。

差し替えは新版PNGを別名で追加し、対応表だけを新版へ切り替えます。旧版ファイル、既に保存されたカード、DB、獲得履歴は残してください。このloaderには削除・アップロード・公開の処理はありません。constructorの第2引数によるroot指定はローカルfixture用のコード注入だけで、requestや設定ファイルから渡してはいけません。
