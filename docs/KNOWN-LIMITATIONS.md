# 既知の制限と検証範囲

## 保存用コードと実環境

このリポジトリではサーバー・チャンネル・Bot・管理者・ロール等の固定IDを、一貫した架空値へ置き換えています。そのまま運用環境へ配置する設定ではありません。実設定、鍵、実参加記録、DB/backup、運用ログ、過去の監査・配備資料は含めません。

## 未検証の実機範囲

- 一般メンバーの参加受付、複数人の同時操作、通常の署名・応答・Gatewayを通した実Discord受理。
- Windows/iPhoneの実カード保存、実添付URL失効後の再取得。
- 実VCでの9分予告・10分自動切断、閉場後の再入室制限。個別メンバーの接続許可は`@everyone`の拒否を上書きできるため、公開権限とは別に確認が必要です。
- 週間ランキングの実投稿、実メンション、予定時刻をまたぐ継続運転。開催10分前通知の実`@here`と端末プッシュ。
- 新しいカテゴリを各メンバーのチャンネル一覧へ追加する操作。閲覧権限、一覧への追加、VC接続は別の条件です。スマホ版の実画面手順は未準備です。

## 実装上の境界

- Discord APIとDBをまたぐ厳密な「必ず1回だけ」は保証しません。送信開始後のタイムアウトや保存失敗は不明として保留し、自動再送しません。
- 切断は実行直前に所属VCを確認しますが、確認とPATCHの間に別VCへ移動する競合を完全にはなくせません。別の移動先を指定してメンバーを移動する機能ではありません。
- 正式な特典画像は未登録でも仮カードを生成できます。素材の権利や配置は運用者が確認します。
- Windowsで作成できないsymlinkや実ファイルの競合差し替えは、隔離した文字列・モック試験と実機結果を区別します。

検証済みの範囲と実行条件は[VALIDATION.md](VALIDATION.md)、実験運用の予定と停止方針は[EXPERIMENTAL.md](EXPERIMENTAL.md)を参照してください。
