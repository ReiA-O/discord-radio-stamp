# Discord ラジオ体操スタンプ

PHPで動くラジオ体操の参加受付・スタンプカードBotです。現在は**実機検証が一部残る実験段階**です。初回開催は2026年10月24日（土）04:00 JSTを予定し、以後は00:00・04:00・07:00・12:30・22:00 JSTの5枠を使用する計画です。準備・配備・実稼働開始を区別し、ソースを保存・公開しただけではBotを起動しません。

**2026-10-21の到達点：** 週間ランキングは本番へOFFのまま反映済みです。新しい10分前通知と開始ゲートはローカル検証済み・本番未配備で、開始用sidecar/wrapper・有効化設定・Cronも未設置です。初回04:00は目標で、稼働予約はまだ完了しておらず、実稼働は開始していません。

このリポジトリは匿名化した開発用コピーです。実サーバー・Bot・ユーザー・チャンネル・ロールのIDは架空値で、実設定・認証情報・参加記録・DB・運用ログを含めません。そのまま本番へ配置する設定ではありません。

## できること

- 体操後の参加受付と同開催の二重押し防止。開催枠ごとに5種類のスタンプを付けます。
- JST参加日数と参加回数を別集計し、月間カードと10・30・60・100・300・365日の特典カード、参加回数ロールを扱います。
- 同じVCを開催30分前に開き、開場済みを確認して開催10分前に案内します。07:00・12:30・22:00枠だけ`@here`、00:00・04:00枠はメンションなしです。
- 開始コマンド成功から9分で予告、10分で閉場・切断。誰も開始しなければ予定時刻30分後に閉場します。
- JST月〜日の開催参加回数を翌月曜07:00にランキング発表する設計です。同率5位も全員掲載し、送信結果不明時の二重投稿を抑止します。

実機で未確認の一般参加・端末保存・自動切断・投稿・継続運転を、上記の設計や隔離試験の成功だけで確認済みとは扱いません。[実験運用](docs/EXPERIMENTAL.md)と[既知の制限](docs/KNOWN-LIMITATIONS.md)を先に確認してください。

## ローカルで試す

1. PHP 8.3と`curl`・`gd`（FreeType/PNG）・`sodium`・`pdo_sqlite`・`sqlite3`・`mbstring`を用意します。メモリ上限は128M以上です。PHP/DLLはこのリポジトリから配布しません。
2. WindowsはBIZ UDゴシック/MSゴシック、Linuxはコードの許可リストにあるIPA/VL/Noto CJK等の日本語フォントを用意します。任意の外部URLからフォントを読みません。
3. 試験出力をリポジトリ外に指定して実行します。

PowerShell:

```powershell
$env:RADIO_STAMP_TEST_ARTIFACT_DIR = Join-Path $env:TEMP ('radio-stamp-tests-' + [guid]::NewGuid().ToString('N'))
php -d memory_limit=128M tests/run.php
Remove-Item Env:\RADIO_STAMP_TEST_ARTIFACT_DIR
```

POSIX shell:

```sh
RADIO_STAMP_TEST_ARTIFACT_DIR="$(mktemp -d)" php -d memory_limit=128M tests/run.php
```

試験は架空データ、隔離SQLite、固定時刻、fake HTTP/Gatewayを使います。実Discordへ投稿したり、運用サーバーへ接続したりしません。変更に関係する個別試験を選んでも構いません。[検証結果と範囲](docs/VALIDATION.md)を参照してください。

## 設定とデータ

`config/*.example.php`は資格情報なし・既定OFFの例です。実設定と秘密は公開ディレクトリ外に置き、コミットしません。固定スコープも架空IDなので、運用者は承認した対象と署名・Bot本人・権限・DB保全・開始ゲート・停止手順を別途照合する必要があります。

正式な特典画像は後日追加できます。現在の`assets/memorial-cards/active.json`は`{}`で、仮カードを生成します。[素材の手順](assets/memorial-cards/README.md)に従い、権利を確認した版付きPNGへ切り替えます。

チャンネルが一覧に出ない場合は[PC版のスクショ付き案内](docs/CHANNEL-DISCOVERY.md)を参照してください。閲覧権限・一覧への追加・VC接続は別の条件です。
